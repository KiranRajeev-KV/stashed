# Architecture Decision Records

Architecture Decision Records (ADRs) capture decisions that affect Stashed's
long-term design. Records are immutable once accepted; a later decision should
supersede the earlier record instead of rewriting its history.

| ---------------------------------------- | -------- | --------------------------------------------------------------------------------- |
